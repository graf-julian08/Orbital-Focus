# Orbital Focus

Fullstack Anwendung zur Produktivitaetssteigerung mit React Frontend und Express Backend.

## Funktionalitaeten
- Uebersichtlicher Code und strukturierte Aufteilung der Komponenten.
- Einfache Integration und Anpassung an bestehende Systeme.

## Nutzung
Navigiere in frontend oder backend und starte die Dienste mit `npm run dev`.
