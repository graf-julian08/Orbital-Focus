# Orbital Focus Application

## Übersicht
**Orbital Focus** ist eine Fullstack-Webanwendung zur Produktivitätssteigerung und Zeitverwaltung. Die Plattform kombiniert ein modern gestaltetes React-Frontend mit einem Express-API-Backend.

## Projektstruktur & Architektur
- `frontend/`: React-Anwendung mit Benutzeroberfläche und Komponenten.
- `backend/`: Node.js/Express API-Server zur Verwaltung von Sitzungsdaten.
- `package.json`: Konfiguration für Abhängigkeiten und Skripte.

## Hauptfunktionalitäten
- **Fokus-Dashboard**: Interaktive Benutzeroberfläche zur Aufgabenübersicht.
- **REST-Schnittstelle**: Backend-Dienst zur Speicherung von Benutzerzuständen.
- **Erweiterbare Architektur**: Modulare Trennung von Client und Server.

## Ausführung & Nutzung
Der Start der Entwicklungsumgebung erfolgt in den jeweiligen Verzeichnissen `frontend/` und `backend/` über `npm run dev`.
